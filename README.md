# My First Site

A personal website I built while learning full stack web development.

## What it has
- A menu, a profile card, and a contact form
- A click counter and a to-do list
- A skills list that is saved with localStorage
- A random joke loaded from an API

- HTML
- CSS (Flexbox and responsive design)
- JavaScript
